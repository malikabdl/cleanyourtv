# TCL C635 (reports as "Smart TV Pro", device BeyondTV4, product BeyondTV6 / G03_4K_GB, board rtd288o / RTD2851M),
# Android TV 11 (API 30), sold in Brazil and Indonesia (Asia-Pacific, AR09 build).
#
# Second unit: TCL C635 4K (BeyondTV4-user 11 RP1A.200622.001 AR09 release-keys, RTD2851M),
# Indonesia / Asia-Pacific (TCL-AP-RTD51M-S1). Tested with CleanYourTV as primary launcher
# over multiple days across multiple reboots.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-c635/debloat.txt
#          (or on Windows: tools\disable.ps1 -TvHost <tv ip> examples\tcl-c635\debloat.txt)
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-c635/debloat.txt
#          (or on Windows: tools\restore.ps1 -TvHost <tv ip> examples\tcl-c635\debloat.txt)
#
# Everything is DISABLED with `pm disable-user --user 0`, never uninstalled.
#
# Stock launcher: com.google.android.apps.tv.launcherx (Google TV launcher), kept enabled on Brazil
#   as fallback or safely disabled and replaced by launcher/ (verified on Indonesia unit).
# Live TV app: com.tcl.tv, with com.tcl.tvinput for the tuner and the HDMI inputs; keep both.
#
# Remote & hardware quirks:
# - On TCL RC902V / RC802N remotes, the dedicated TV button emits KEYCODE_TV (170 / 4001). The system
#   window policy maps it to non-existent com.android.tv; map 170:com.tcl.tv/.TVActivity and
#   4001:com.tcl.tv/.TVActivity in app_keys with HomeKeyService/InputKeyService (see config.json).
# - The remote's gear button emits keycode 83 / 4077 (settings_key_keycodes).
# - TV turning off immediately after standby wake fixed via hdmi_control_auto_device_off_enabled=0.
#
# Kept enabled on both units:
# - Hardware tuner & inputs: com.tcl.tv, com.tcl.tvinput
# - Core system: com.tcl.providers.config, com.tcl.initsetup, com.tcl.system.server, com.tcl.settings
# - Bluetooth & remote: com.tcl.tcl_bt_rcu_service, com.tcl.autopair
# - Chromecast built-in: com.google.android.apps.mediashell
# - System OTA updater: com.tcl.versionUpdateApp
